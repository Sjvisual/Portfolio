# Sudhanshu Prakash Shashi — Portfolio

**Senior Backend Developer | AI Evaluator | Full-Stack Engineer**

Professional portfolio website built with pure HTML, CSS, and JavaScript. No frameworks, no build tools — just open `index.html` in any browser.

## 🚀 GitHub Pages Deployment

1. Push this folder to a GitHub repository
2. Go to **Settings → Pages**
3. Set source to **`main` branch / `root`**
4. Your site will be live at `https://<your-username>.github.io/<repo-name>/`

## 📁 Project Structure

```
portfolio-html/
├── index.html   ← Full portfolio HTML (all 8 sections)
├── style.css    ← All styles (design tokens, layout, responsive)
├── script.js    ← Navbar, mobile menu, animations, scroll

```
